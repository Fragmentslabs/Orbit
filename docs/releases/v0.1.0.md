# Orbit — Release v0.1.0

**Date:** 2026 · **Branch:** `homolog` · **Tag:** `v0.1.0`

First public release of Orbit: the AI-powered coding assistant for desktop (Windows) with a mobile companion (Android / iOS).

---

## Desktop app (Electron)

### Agent engine
- **Modes**: Plan (read-only analysis), Build (implementation) and Orchestrate (multi-agent coordination)
- **Subagents**: delegate subtasks to specialized agents, each with focused context; results reviewed before integration
- **Plan review loop**: proposed plans are reviewed before execution starts
- **Reasoning levels**: per-task reasoning depth, with lightweight model variants for quick passes
- **Permission modes**: per-chat control from "ask before acting" to full autonomy
- **Scheduled messages**: queue prompts to be sent at a chosen time
- **Skills**: reusable instruction sets applied on demand by the agent
- **Persistent memory**: project conventions and preferences remembered across sessions

### Models & providers
- Anthropic, OpenAI, Google (incl. Vertex AI), Azure OpenAI, Amazon Bedrock, Cohere
- Any OpenAI-compatible endpoint via custom providers
- Live models.dev catalog: search, pricing, speed and capability badges
- Per-chat model selection with provider/endpoint management

### Tools
- **Files**: read / write / edit / list / glob / grep, with per-message **snapshots** and one-click revert
- **Terminal**: integrated PTY with output streaming and process control
- **Browser**: built-in tab to test web apps
- **Web**: search (Exa) and page reading for research
- **MCP**: connect external Model Context Protocol servers; skills panel for managing them
- **Diff review**: inline side-by-side diff after changes

### Workspace & UI
- Working folders per chat; multi-folder support
- Right panel tabs: chat, terminal, folders, browser, diff
- Markdown preview with view/edit toggle; syntax highlighting
- Git branch selector with **create branch** flow (checkout `-b` from the UI)
- Chat search, file palette, slash commands
- i18n: **English** and **pt-BR**
- Appearance settings (dark/light), usage analytics and activity heatmap

## Mobile companion (Expo / React Native)

- Pair with the desktop app over the local network via QR code
- Remote chat — same sessions as the desktop
- Manage preferences, providers, tools, memories and notifications from the phone
- Usage overview and theme/language/appearance settings

## Architecture

```
apps/desktop   Electron desktop app (React + Vite + Tailwind)
apps/mobile    Expo / React Native companion
packages/shared         Data models & session format
packages/companion-client  Mobile ↔ desktop networking
packages/protocol       Wire protocol
packages/sdk            Client SDK
```
